## Decision and execution

  working copies,10 cards, historical source/PR records and legacy experiment preserved.
- Interpret “all” as broad, explicit coverage rather than an impossible global-completeness
  promise.73 selected canonical primary repositories,15 multi-label routes,146 pinned files.
- Distinguish learning paradigms, domains and engineering; keep sources, rights and
  proposals separate from measured model results. No third-party vendor trees or data.
- Capture public GraphQL metadata/root files, then read pinned README/LICENSE in small
  batches. Validate Git blob SHA1, byte length and SHA256 before publishing metadata.
- Three canonical redirects retained. Two archives and five API unclassified licenses
  remain explicit. Read fixed text; MAE noncommercial reference, mixed component notices,
  TorchAudio maintenance, and Faiss clustering support are not flattened away.
- Follow-up annotation regeneration used explicit resume; retained actual original API
  observation times rather than presenting cache reads as fresh network research.
