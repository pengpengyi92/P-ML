- Preserve the frozen73-project catalog and10 historical detailed cards. Select43 new
  primary repositories by task/role; verify the canonical union before reporting116.
  This is curation, not full organization enumeration, a star ranking or a global census.
- Reuse the same byte-checked public GraphQL collector. Pin default-branch commits,
  README, root license and explicitly requested additional root license files. Record
  original query times, Git blob IDs, byte sizes and SHA256. Resume never refreshes timestamps.

  dataset tooling and simulator. A research release or non-archived repo does not imply
  ongoing maintenance, supported local installation or reproduced paper performance.

- Raw source/cache stay in ignored `.local/`; no mirrors, checkpoints, datasets, private
  P University material, credentials or external issue/PR/discussion posts.
- New collector options are constrained below this project's `ml-repo/`. Default15-route
  behavior remains compatible; additional source paths must be observed root files.
- Validate snapshot/selection parity,43+73 non-overlap,89 source pins, roles, timezone,
  rights, local links, LF output, path and privacy negatives; rerun previous tests and
  unchanged feature-scaling tests. Run deterministic rendering for both catalogs.

No upstream code installation/execution, simulation, policy training, model inference,
paid compute or real-world deployment is performed. Catalog checks are not ML evaluation.
