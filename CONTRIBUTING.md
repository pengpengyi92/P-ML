# Contributing to P-ML

We welcome resource suggestions and your own ML research, including small algorithms, pedagogical implementations, replications, and negative results.

1. Share ML/DL/RL repos, papers or ideas at [intake #2](https://github.com/pengpengyi92/P-ML/issues/2) or the [Research Exchange #3](https://github.com/pengpengyi92/P-ML/discussions/3). The Issue tracks submissions; the Discussion hosts technical conversation and the curated index. Post in one place and cross-link if needed. The [general call #1](https://github.com/pengpengyi92/P-ML/issues/1) remains open.
2. Search the relevant index and open issues for duplicates. For a straightforward, nonduplicate addition, a pull request can go directly to the appropriate index.
3. Choose **ML / DL / RL / Combined** and **Repo / Project / Paper / Idea / Reproduction**. Include title, primary public URL (optional for an original idea), original credit, why it is useful and one starting point. Papers should state version and publication status, including whether a preprint, workshop, conference or journal entry. Disclose your relationship to the work and any AI/Agent assistance. Note license, data or access limits.
4. For an experiment, include **question, baseline, data and split, protocol and commands, results, and limitations**. Report what you actually ran; mark proposed measurements `UNMEASURED`.

Use links and original commentary rather than reposting third-party assets. Submit only material you are authorized to share. Do not post private P University content, datasets, credentials, or personal information in Issues, Discussions, or PRs.

Agents may help check sources, deduplicate, summarize evidence and draft a
contribution under human review and authorization. Do not automatically post,
install or run submitted code. Catalog inclusion is discovery, not validation or
an endorsement. Label execution `NOT_RUN` when not checked independently.
